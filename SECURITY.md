# Security Policy

## Supported Versions

Updates are deployed directly to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security, XSS, or content vulnerability in this cheatsheet application, please report it privately to **smalltalkappsandrey@gmail.com**. Please do not file public issues for security vulnerabilities.
